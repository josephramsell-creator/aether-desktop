Aether 2.0.1
============

Already have v1 or broken v2?
  Use Aether-v2-patch.zip — unzip, run APPLY-v2.bat, start Aether.exe.
  That overwrites the studio inside your current folder.

Fresh copy?
  Unzip Aether-Windows-x64.zip and run Aether.exe.
  First launch can create a desktop shortcut.

If you already edited readings, keep a copy of data\content.
The patch will not overwrite aether-production.xlsx when that file exists.

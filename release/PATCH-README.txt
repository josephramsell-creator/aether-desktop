Aether 2.0.0 update patch
=========================

Use this if you already have Aether 1.0 installed.
It replaces the app inside your existing folder (~55 MB).
It does not replace Aether.exe or Chromium.

1. Close Aether.
2. Unzip this archive.
3. Double-click APPLY-v2.bat
   — if it cannot find Aether.exe, paste the folder that contains it.
4. Start Aether.exe

The patch overwrites resources\app.asar (the studio).
It only adds aether-production.xlsx if that file is not already there,
so edited readings are not overwritten.

Fresh install instead? Download the full pack:
https://github.com/josephramsell-creator/aether-desktop/releases/download/v2.0.0/Aether-Windows-x64.zip
